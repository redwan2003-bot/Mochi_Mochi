Web Bluetooth is required to communicate directly with Mochi Bot over GATT. Please open this dashboard using Google Chrome, Microsoft Edge, or Opera on Windows, macOS, ChromeOS, or Android. (Firefox and iOS Safari do not support the Web Bluetooth standard).

Local Origin Security Constraint (file:// protocol)

For security, Chromium browsers only enable Web Bluetooth on HTTPS or http://localhost. To connect to physical hardware, serve this directory via a local HTTP server:

python -m http.server 8080 then visit http://localhost:8080
